Quantos traços tem 淑?

11. denso, vale escrever devagar. Veja a animação acima se quiser a ordem e não só o número.

Como 淑 é pronunciado?

shū, alto e plano. Cole no conversor de hanzi para pinyin para ver como se lê dentro de uma frase completa: caracteres polifônicos mudam de leitura conforme o contexto.
